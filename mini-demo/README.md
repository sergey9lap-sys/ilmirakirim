# Тестовое мини-приложение Ильмиры

Изолированный предпросмотр `/mini-demo/`: клиентская главная, три урока, бонусы, приглашения и профиль. Все записи вымышленные; общая маркировка видна на каждом экране. Никаких форм, платежей, API заявок, чтения личных Telegram-данных или серверного хранения пользователей. Четыре булевых признака прогресса хранятся только в localStorage данного браузера. Ссылка `?ref=demo` показывает демонстрационное приглашение, не регистрирует клиента. SDK Telegram используется для оформления окна, кнопки назад, выбора получателя и открытия внешних контактных ссылок по нажатию пользователя.

Для подключения использовать существующий бот, не менять webhook/getUpdates/уведомления. Персональная кнопка меню для чата владельца предпочтительна; общее меню подключать только после выбора пользователя. Перед заменой сохранить предыдущую кнопку для отката. Настоящее начисление, аутентификация Telegram initData, идентификация рефералов, видео и согласованные правила программы — отдельная разработка.

Публичное демо: https://ilmirakirim.com/mini-demo/. Бот: @Ilmirakirimbot. На 3 октября 2026 года приложение опубликовано, существующее меню проверено (`commands`); кнопка демо ещё не установлена — ожидается выбор персонального или общего меню. Для персональной кнопки потребуется ID чата владельца. Проверка на настоящем устройстве внутри Telegram ещё не выполнена.

Для показа: открыть главную, продолжить обучение, отметить урок пройденным; открыть «Бонусы» → «Пригласить знакомого», скопировать или поделиться ссылкой. Проверочное начисление и сброс: «Профиль» → «Проверить демо». Заявки и деньги по-прежнему не затрагиваются.

Обновление подключения, 3 октября 2026: по запросу пользователя установлена персональная кнопка «Демо-кабинет» для его чата. Повторное чтение Telegram API подтвердило `web_app` и адрес демо; общее меню осталось `commands`. Предыдущее персональное меню сохранено на сервере в закрытом резервном файле для отката.
