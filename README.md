# Сайт Ильмиры Кирим

Самостоятельная статическая копия актуальной страницы из `personal-world/sites/ilmira`, перенесённая 23 сентября 2026 года. Прежняя версия по `/p/ilmira` остаётся в `myworld` и не изменена. Репозитории не синхронизируются автоматически.

## Размещение

`index.html` находится в корне: для показа сайта достаточно направить веб-сервер на каталог репозитория. Сборка и Node.js на сервере не нужны. Все используемые файлы — `assets/`, `documents/`, `vendor/`, `style.css`, `client-feedback.css` и `app.js` — уже включены.

Для будущих отдельных страниц можно добавлять каталоги вида `имя-страницы/index.html`, сохраняя главную страницу в корне.

## Перед переключением домена

- В `index.html`, `robots.txt` и `sitemap.xml` пока указан адрес прежней копии `https://space.lpsflow.ru/p/ilmira`. После получения постоянного домена заменить его в canonical, Open Graph, структурированных данных и карте сайта.
- Проверить настройки домена, HTTPS и работу всех ссылок, форм и документов на новом сервере.
- Копирование в этот репозиторий не обновляет прежнюю страницу автоматически; дальнейшие правки для нового домена вносить сюда отдельно.
